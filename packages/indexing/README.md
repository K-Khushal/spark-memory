# @spark/indexing

Indexing providers behind one interface: extraction (Gemma 4 → Gemini), categorisation (Jev), colours, embeddings, Deep fetch and the fallback chain (ADR-0005, ADR-0008, ADR-0010).

Entry point: `index.ts`. Implementation goes in `lib/`, tests in `tests/` (see [packages/README.md](../README.md)).
